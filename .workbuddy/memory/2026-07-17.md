# 2026-07-17 工作日志

## 视频通话软件项目 - 从零搭建完成

### 技术选型确认
- 路线 A: **Flutter + WebRTC P2P 点对点**
- 客户端: Flutter (Windows/Android) + flutter_webrtc
- 信令服务: Python asyncio + websockets
- 传输: WebRTC P2P（SRTP 加密，媒体流不经服务器）

### 完成的模块

1. **Flutter 项目初始化** (`pubspec.yaml`, `analysis_options.yaml`)
   - 依赖: flutter_webrtc, web_socket_channel, provider, uuid, logger

2. **数据模型** (`lib/models/`)
   - `signal_message.dart` - 信令消息协议定义（JSON 格式）
   - `room.dart` - 房间和用户信息模型

3. **信令服务** (`lib/services/signaling_service.dart`)
   - WebSocket 连接管理
   - 房间加入/离开
   - SDP Offer/Answer/Candidate 中继
   - 呼叫控制（call/accept/reject/hangup）
   - 消息分发回调机制

4. **WebRTC 服务** (`lib/services/webrtc_service.dart`)
   - 本地音视频采集与渲染
   - RTCPeerConnection 创建与管理
   - 完整的 P2P 协商流程（Caller: Offer→Answer, Callee: Answer）
   - ICE 候选收集与交换
   - DataChannel 支持（文本/文件传输）
   - 摄像头切换、静音/视频控制

5. **ViewModel** (`lib/viewmodels/call_viewmodel.dart`)
   - 完整的状态机：idle → connecting → connected → inRoom → calling/ringing → onCall
   - 编排信令服务和 WebRTC 服务的交互
   - 处理所有异常场景（拒绝、超时、断连）

6. **UI 界面** (`lib/pages/`)
   - `home_page.dart` - 首页：服务器连接 + 房间号输入/生成
   - `call_page.dart` - 通话页：全屏远程视频 + 本地画中画 + 控制栏 + 振铃动画

7. **Python 信令服务器** (`server/signaling_server.py`)
   - WebSocket 服务器，支持多客户端并发
   - 房间管理（最多2人 P2P）
   - 消息中继（offer/answer/candidate）
   - 心跳检测、重复登录处理、异常清理
   - 启动命令: `python server/signaling_server.py --port 8765`
